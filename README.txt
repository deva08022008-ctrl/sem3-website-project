DEVA PORTFOLIO — LIGHT GREEN THEME

Files:
- index.html: portfolio page
- style.css: light-green gradient styling and Times New Roman font
- script.js: navigation, theme toggle, project filters and contact form behavior
- deva-profile.png: Deva's background-removed profile image

How to run:
1. Extract the ZIP into one folder.
2. Keep all four files in the same folder.
3. Open index.html in your browser.

The profile photo is fixed in the page and cannot be changed through an upload button.
The photo box stays square. The site uses a light-green gradient theme and Times New Roman.
